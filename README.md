# leahbao_poops

鬣寶固定有吃亞幸中藥保養，定期（每兩週）提供排泄及生活症狀記錄作為每次中藥調配參考。  
註：此紀錄方式格式非醫院要求，不專業琢磨調整中。  

問過醫院，不需面對面看回診，透過信件、照片影片看狀況調整中藥即可（照片有時色偏較難拍出真實狀態）。  
因初期不知什麼要回報怎樣的資訊，先以記錄排泄物和較關心的症狀狀態，或許醫師看了會給予意見，但未有過相關建議，不確定這樣資訊對他們的作用，但本就有記錄，便同步提供。   

### 與醫院互動模式
- Mail 前兩週記錄，同時預約下兩週中藥。
- 院方不會特別回信或告知有無收到信件：
   - 記得電聯櫃檯收信。有時候醫師出國或長假，櫃檯此時會告知，通常是照舊寄出。中藥是吃長期，偶爾幾次斷掉不要緊。  
   - 若信中有問問題，要主動追蹤追問，醫師不一定會回信。  
   - 仍須注意有無回信：平時不會特別回信，偶爾會在寄出中藥時會有回信。早期回應問題有透過信件回覆；有過在換季時，主動提醒調整照顧方式！

## 自動化生成報告
1. 新增當期近況記錄 [ctrl+點](https://docs.google.com/spreadsheets/d/12m-ozdcdyN4JvdidQBRCjL2lsi5pqk1sRjpjAUaWMzY/edit) 
2. 匯入照片到該日資料夾：在 repo 建立（符合當期日期的）資料夾結構。
3. 到 Action run workflow 產生 `tmpLog.md`
4. 讓 my skill 分析照片、增加註記：  
   貼入`tmpLog.md` url 將自動生成 log.md 並自動 commit；  
   直接貼 `tmpLog.md` 內容，將只回覆生成內容，後續需手動建立檔案。
